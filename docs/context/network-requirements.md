## Connectivity Resilience

| Feature | Behavior |
|---------|----------|
| MQTT offline buffer | Device buffers readings locally, pushes on reconnect |
| Backfill | Platform auto-detects gaps and backfills from device/S3 |
| Stale data alert | Notification if no data received for > 4h (configurable) |
| Frontend offline | SPA cached in browser, shows last-known data |
