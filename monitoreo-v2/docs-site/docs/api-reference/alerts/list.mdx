# Listar alertas

<span className="api-method api-method--get">GET</span> `/alerts`

Obtiene la lista de alertas filtradas por estado, severidad, edificio o medidor.

## Autenticacion

Requiere cookie JWT de sesion activa.

## Parametros

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `status` | string | No | Estado de la alerta. Valores: `active`, `acknowledged`, `resolved`. |
| `severity` | string | No | Severidad. Valores: `critical`, `high`, `medium`, `low`. |
| `buildingId` | string | No | UUID del edificio para filtrar alertas. |
| `meterId` | string | No | UUID del medidor para filtrar alertas. |

## Respuesta

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID de la alerta. |
| `buildingId` | string | UUID del edificio asociado. |
| `meterId` | string | UUID del medidor asociado. |
| `severity` | string | Severidad: `critical`, `high`, `medium`, `low`. |
| `status` | string | Estado: `active`, `acknowledged`, `resolved`. |
| `message` | string | Mensaje descriptivo de la alerta. |
| `alertType` | string | Tipo de alerta. |
| `createdAt` | string | Fecha de creacion (ISO 8601). |
| `acknowledgedAt` | string | Fecha de reconocimiento (ISO 8601). |
| `resolvedAt` | string | Fecha de resolucion (ISO 8601). |
| `resolutionNotes` | string | Notas de resolucion. |

## Ejemplo

```bash
curl -X GET "https://power-monitor.cloud/api/alerts?status=active&severity=critical" \
  --cookie "access_token=<JWT>"
```
