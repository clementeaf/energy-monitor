# Resolver alerta

<span className="api-method api-method--patch">PATCH</span> `/alerts/{id}/resolve`

Marca una alerta como resuelta con notas opcionales. Requiere permiso `alerts:manage`.

## Autenticacion

Requiere cookie JWT de sesion activa. Permiso requerido: `alerts:manage`.

## Parametros de ruta

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `id` | string | Si | UUID de la alerta a resolver. |

## Body

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `resolutionNotes` | string | No | Notas de resolucion describiendo la accion tomada. |

## Respuesta

Retorna la alerta con `status=resolved`, `resolvedAt` y `resolutionNotes` actualizados.

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID de la alerta. |
| `buildingId` | string | UUID del edificio asociado. |
| `meterId` | string | UUID del medidor asociado. |
| `severity` | string | Severidad: `critical`, `high`, `medium`, `low`. |
| `status` | string | Siempre `resolved` en respuesta exitosa. |
| `message` | string | Mensaje descriptivo de la alerta. |
| `alertType` | string | Tipo de alerta. |
| `createdAt` | string | Fecha de creacion (ISO 8601). |
| `acknowledgedAt` | string | Fecha de reconocimiento si fue reconocida previamente. |
| `resolvedAt` | string | Fecha de resolucion (ISO 8601). |
| `resolutionNotes` | string | Notas de resolucion proporcionadas. |

## Ejemplo

```bash
curl -X PATCH "https://power-monitor.cloud/api/alerts/a1b2c3d4-e5f6-7890-abcd-ef1234567890/resolve" \
  -H "Content-Type: application/json" \
  --cookie "access_token=<JWT>" \
  -d '{"resolutionNotes": "Transformador reemplazado. Voltaje normalizado."}'
```

  "meterId": "m1234567-89ab-cdef-0123-456789abcdef",
  "severity": "critical",
  "status": "resolved",
  "message": "Voltaje fuera de rango en medidor M-001",
  "alertType": "voltage_out_of_range",
