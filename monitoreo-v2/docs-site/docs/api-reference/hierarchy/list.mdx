# Listar jerarquia de edificio

<span className="api-method api-method--get">GET</span> `/hierarchy/buildings/{buildingId}`

Retorna el arbol de nodos jerarquicos de un edificio (pisos, zonas).

## Autenticacion

Requiere cookie JWT valida. El edificio debe pertenecer al tenant del usuario.

## Parametros de ruta

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `buildingId` | string | Si | UUID del edificio. |

## Respuesta

Retorna un array de `HierarchyNode`. La estructura de arbol se reconstruye via `parentId`.

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID del nodo. |
| `buildingId` | string | UUID del edificio al que pertenece. |
| `name` | string | Nombre del nodo (ej. "Piso 3", "Zona Foodcourt"). |
| `levelType` | string | Tipo de nodo: `building`, `floor` o `zone`. |
| `parentId` | string | UUID del nodo padre. `null` para nodos raiz. |
| `sortOrder` | number | Orden de visualizacion dentro del mismo nivel. |
| `metadata` | object | Metadatos adicionales del nodo (superficie, codigo, etc.). |
| `createdAt` | string | Fecha de creacion (ISO 8601). |

## Ejemplo

```bash
curl -X GET https://power-monitor.cloud/api/hierarchy/buildings/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  --cookie "access_token=eyJhbGciOi..."
```
