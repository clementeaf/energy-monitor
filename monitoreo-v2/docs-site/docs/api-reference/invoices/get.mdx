# Obtener factura

<span className="api-method api-method--get">GET</span> `/invoices/{id}`

Obtiene el detalle de una factura incluyendo sus line items.

## Autenticacion

Requiere cookie JWT de sesion activa.

## Parametros de ruta

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `id` | string | Si | UUID de la factura. |

## Respuesta

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID de la factura. |
| `buildingId` | string | UUID del edificio. |
| `invoiceNumber` | string | Numero de factura. |
| `status` | string | Estado: `draft`, `pending`, `approved`, `voided`. |
| `periodStart` | string | Inicio del periodo facturado (ISO 8601). |
| `periodEnd` | string | Fin del periodo facturado (ISO 8601). |
| `totalAmount` | number | Monto total de la factura. |
| `notes` | string | Notas adicionales. |
| `createdAt` | string | Fecha de creacion (ISO 8601). |
| `lineItems` | array | Lista de items de la factura. |

**Propiedades de line item:**

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID del line item. |
| `meterId` | string | UUID del medidor. |
| `description` | string | Descripcion del cargo. |
| `quantity` | number | Cantidad (kWh, kW, etc.). |
| `unitPrice` | number | Precio unitario. |
| `amount` | number | Monto total del item. |
| `blockName` | string | Nombre del bloque tarifario aplicado. |

## Ejemplo

```bash
curl -X GET "https://power-monitor.cloud/api/invoices/f1234567-89ab-cdef-0123-456789abcdef" \
  --cookie "access_token=<JWT>"
```
