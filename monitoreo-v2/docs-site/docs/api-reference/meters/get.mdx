# Obtener medidor

<span className="api-method api-method--get">GET</span> `/meters/{id}`

Retorna un medidor por su ID. Debe pertenecer a un edificio del tenant del usuario.

## Autenticacion

Requiere cookie JWT valida.

## Parametros de ruta

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `id` | string | Si | UUID del medidor. |

## Respuesta

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID del medidor. |
| `buildingId` | string | UUID del edificio al que pertenece. |
| `name` | string | Nombre del medidor. |
| `code` | string | Codigo interno del medidor. |
| `meterType` | string | Tipo: `main`, `submeter` o `check`. |
| `phaseType` | string | Fase: `single` o `three`. |
| `serialNumber` | string | Numero de serie. |
| `manufacturer` | string | Fabricante. |
| `model` | string | Modelo. |
| `loadCategory` | string | Categoria de carga. |
| `isActive` | boolean | Estado activo/inactivo. |
| `iotDeviceId` | string | UUID del dispositivo IoT asociado. |
| `createdAt` | string | Fecha de creacion (ISO 8601). |
| `updatedAt` | string | Fecha de ultima actualizacion (ISO 8601). |

## Ejemplo

```bash
curl -X GET https://power-monitor.cloud/api/meters/d4e5f6a7-b8c9-0123-defa-456789012345 \
  --cookie "access_token=eyJhbGciOi..."
```
