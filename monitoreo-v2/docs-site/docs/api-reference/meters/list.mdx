# Listar medidores

<span className="api-method api-method--get">GET</span> `/meters`

Retorna todos los medidores del tenant actual. Opcionalmente filtrados por edificio.

## Autenticacion

Requiere cookie JWT valida. Scoping automatico por tenant y permisos de edificios.

## Parametros

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `buildingId` | string | No | UUID del edificio para filtrar medidores. |

## Respuesta

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID del medidor. |
| `buildingId` | string | UUID del edificio al que pertenece. |
| `name` | string | Nombre del medidor. |
| `code` | string | Codigo interno del medidor. |
| `meterType` | string | Tipo de medidor: `main`, `submeter` o `check`. |
| `phaseType` | string | Tipo de fase: `single` o `three`. |
| `serialNumber` | string | Numero de serie del equipo. |
| `manufacturer` | string | Fabricante del medidor. |
| `model` | string | Modelo del medidor. |
| `loadCategory` | string | Categoria de carga. |
| `isActive` | boolean | Estado activo/inactivo. |
| `iotDeviceId` | string | UUID del dispositivo IoT asociado (si existe). |
| `createdAt` | string | Fecha de creacion (ISO 8601). |
| `updatedAt` | string | Fecha de ultima actualizacion (ISO 8601). |

## Ejemplo

```bash
curl -X GET "https://power-monitor.cloud/api/meters?buildingId=a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  --cookie "access_token=eyJhbGciOi..."
```
