# Actualizar medidor

<span className="api-method api-method--patch">PATCH</span> `/meters/{id}`

Actualiza campos parciales de un medidor existente.

## Autenticacion

Requiere cookie JWT valida. Permiso `meters:update`.

## Parametros de ruta

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `id` | string | Si | UUID del medidor. |

## Body

Todos los campos son opcionales. Solo se actualizan los campos enviados.

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `name` | string | No | Nombre del medidor. |
| `code` | string | No | Codigo interno. |
| `meterType` | string | No | Tipo: `main`, `submeter` o `check`. |
| `phaseType` | string | No | Fase: `single` o `three`. |
| `serialNumber` | string | No | Numero de serie. |
| `manufacturer` | string | No | Fabricante. |
| `model` | string | No | Modelo. |
| `loadCategory` | string | No | Categoria de carga. |
| `isActive` | boolean | No | Estado activo/inactivo. |

## Respuesta

Retorna el medidor actualizado con todos sus campos.

## Ejemplo

```bash
curl -X PATCH https://power-monitor.cloud/api/meters/d4e5f6a7-b8c9-0123-defa-456789012345 \
  --cookie "access_token=eyJhbGciOi..." \
  -H "Content-Type: application/json" \
  -d '{
    "serialNumber": "SN-2024-00456",
    "manufacturer": "Siemens",
    "model": "SENTRON PAC3220"
  }'
```
