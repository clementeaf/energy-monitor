# Ultimas lecturas

<span className="api-method api-method--get">GET</span> `/readings/latest`

Retorna la lectura mas reciente por cada medidor. Util para monitoreo en tiempo real y dashboards.

## Autenticacion

Requiere cookie JWT valida. Scoping automatico por tenant y permisos de edificios.

## Parametros

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `buildingId` | string | No | UUID del edificio para filtrar medidores. |
| `meterId` | string | No | UUID de un medidor especifico. |

## Respuesta

Array con la ultima lectura de cada medidor que cumple los filtros.

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `meter_id` | string | UUID del medidor. |
| `building_id` | string | UUID del edificio. |
| `timestamp` | string | Marca de tiempo de la lectura (ISO 8601). |
| `power_kw` | number | Potencia activa en kW. |
| `voltage_l1` | number | Voltaje fase L1 en V. |
| `current_l1` | number | Corriente fase L1 en A. |
| `power_factor` | number | Factor de potencia (0-1). |
| `energy_kwh` | number | Energia acumulada en kWh. |
| `frequency` | number | Frecuencia en Hz. |

## Ejemplo

```bash
curl -X GET "https://power-monitor.cloud/api/readings/latest?buildingId=a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  --cookie "access_token=eyJhbGciOi..."
```
