# Listar usuarios

<span className="api-method api-method--get">GET</span> `/users`

Retorna todos los usuarios del tenant actual. Super admins pueden consultar cross-tenant.

## Autenticacion

Requiere cookie JWT valida. Permiso: `admin_users:read`.

## Parametros

| Nombre | Tipo | Requerido | Descripcion |
|--------|------|-----------|-------------|
| `crossTenant` | boolean | No | Solo para `super_admin`. Si `true`, retorna usuarios de todos los tenants. Default: `false`. |
| `buildingIds` | string | No | IDs de edificios separados por coma. Filtra usuarios asignados a esos edificios. |

## Respuesta

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `id` | string | UUID del usuario. |
| `email` | string | Email del usuario (PII descifrado). |
| `displayName` | string | Nombre visible del usuario. |
| `isActive` | boolean | Estado activo/inactivo. |
| `phone` | string | Telefono del usuario. |
| `role` | object | Rol asignado: `id` (UUID), `name` (string), `slug` (string). |
| `buildingIds` | string[] | IDs de edificios asignados al usuario. |
| `createdAt` | string | Fecha de creacion (ISO 8601). |

## Ejemplo

```bash
curl -X GET https://power-monitor.cloud/api/users \
  --cookie "access_token=eyJhbGciOi..."
```

```bash title="cross-tenant"
curl -X GET "https://power-monitor.cloud/api/users?crossTenant=true&buildingIds=uuid1,uuid2" \
  --cookie "access_token=eyJhbGciOi..."
```
