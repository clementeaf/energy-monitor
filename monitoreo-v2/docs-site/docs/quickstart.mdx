## 1. Obtener acceso

Un administrador de tu organizacion debe crear tu usuario desde la plataforma en
**Administracion > Usuarios**. Recibiras un email de invitacion con instrucciones.

1. **Aceptar invitacion** -- Haz click en el link de invitacion recibido por email. Se te redirigira a la plataforma.
2. **Login via OAuth** -- Inicia sesion con tu cuenta Microsoft o Google corporativa. El sistema te autenticara y asignara los permisos de tu rol.
3. **Configurar MFA** -- Si tu rol requiere MFA, se te mostrara un codigo QR para configurar tu app authenticator (Google Authenticator, Microsoft Authenticator, etc.).

## 2. Autenticacion API

La API usa cookies httpOnly. Para autenticarte programaticamente:

```bash
# Login con token OAuth
curl -X POST https://power-monitor.cloud/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"provider": "google", "token": "<tu-id-token>"}'

# La respuesta setea cookies httpOnly automaticamente
# Usa -b y -c para mantener la sesion:
curl -b cookies.txt -c cookies.txt \
  https://power-monitor.cloud/api/auth/me
```

## 3. Tu primera llamada

```bash
# Listar edificios de tu tenant
curl -b cookies.txt https://power-monitor.cloud/api/buildings
```

## 4. Consultar lecturas

```bash
# Ultimas lecturas de un edificio
curl -b cookies.txt \
  "https://power-monitor.cloud/api/readings/latest?buildingId=550e8400-..."
```

  {
